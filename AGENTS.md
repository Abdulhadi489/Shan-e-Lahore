# Instructions for AI coding assistants

Read `CLAUDE.md` first and follow it: it holds the project rules (stack, security, working agreement). Then read `docs/status.md` for what is done, what is next and what is waiting on someone.

Before every push, update `docs/status.md` and `docs/decisions.md` as `CLAUDE.md` section 16 describes. Never push, open a pull request or deploy without asking the person you are working with.
